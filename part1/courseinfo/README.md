# CourseInfo - React Basics

A minimal React application demonstrating component structure and props.

## Features
- 📝 Displays course information
- 🧩 Component-based architecture
- 📊 Calculates total exercises

## Technologies
- ⚛️ React 18
- ⚡ Vite (build tool)
- No CSS/styling (pure HTML structure)

## Clone the repository
- git clone https://github.com/hpord/fullstackopen.git
- cd part1/courseinfo

## Install dependencies
- npm install

## Run development server
- npm run dev
- Then open http://localhost:5173 in your browser
